# MCP Builder brand

Two offset blocks fit together: a solid base supports an emerald connector with two plug pins. The mark stands for turning an existing API into tools that agents can connect to and use. It was generated with Codex CLI.

## Colors

- Emerald: `#22c55e` (connector and “MCP”)
- Near-black: `#0a0a0a` (favicon background)
- Neutral: `currentColor` for the main mark; `#71717a` in the wordmark so the SVG image reads on light and dark README backgrounds
- Optional light accent: `#86efac`

## Files and use

- `mcp-builder-mark.svg`: two-color mark; set CSS `color` to a dark value on light surfaces or a light value on dark surfaces.
- `mcp-builder-mark-mono.svg`: single-ink mark; set CSS `color` to the desired ink.
- `mcp-builder-favicon.svg`: dark rounded square, ready for a browser tab.
- `mcp-builder-wordmark.svg`: mark with “MCP Builder” for README and headers.
- `mcp-builder-concept.png`: exploratory dark-background concept render.

Use the standalone mark at **16 px or larger**; use the wordmark at **160 px wide or larger**. Keep at least one pin-width of clear space around the mark. Do not stretch, rotate, recolor the emerald, add gradients, or place the unmodified two-color mark on a background that hides its base.
