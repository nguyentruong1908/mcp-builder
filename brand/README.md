# MCP Factory logo

The sawtooth roof is a factory; the cutout `>_` is the Codex CLI prompt; two pins suggest an MCP connector.
The mark uses a 64 × 64 grid with broad shapes for small icons.
`logo-mark.svg` and the wordmark use `currentColor` for the main shape and text.
Color tokens: emerald `#22c55e`, near-black `#0a0a0b`, and optional off-white `#f5f5f4` for dark surfaces.
Use `logo-mark-mono.svg` when only one ink is available; set CSS `color` to theme the mark.
The favicon places the near-black mark on emerald; `logo-concept.png` is the exploratory render.
